启动器分为2个大类：[官方启动器]{.text-story} 和 [社区启动器]{.text-story}

### 社区启动器

社区启动器种类繁多，PVP/生存/休闲/各类模组等，玩家喜好不一，因此社区启动器比较丰富。

在这里，我们了解适用于大多数玩家的两个启动器。

HMCL是我最喜欢的Minecraft启动器，下载简单快速，安装方便，小白也可轻松上手操作。

#### 为HMCL挑选一个合适的存储位置

::alert{type="error" title="重要！"}

### HMCL安装

#### Java？

没错， **HMCL** 使用 **Java** 开发的，所以运行 **HMCL** 要求计算机有 **Java** 环境。

我提问了 **Copilot** 它列出了一些常见的 **Java** 发行版，同时我发现 **Copilot** 引用了另一个博客作者的文章进行推荐，所以我在下面列出了与 **Copilot** 的对话链接和另一个博客作者的文章链接

| **发行版** | **优点** | **缺点** | **适合场景** |
| --- | --- | --- | --- |
| **Temurin (Adoptium)** | 稳定、兼容性强、社区推荐 | 无明显缺点 | MC客户端推荐 |
| **Zulu (Azul)** | 模组兼容好，企业支持强 | 安装包较大 | 大型模组整合包 |
| **Liberica (BellSoft)** | 提供 JavaFX，适合 GUI 应用 | 社区规模较小 | 启动器或 GUI 程序 |
| **Microsoft OpenJDK** | Windows/Azure优化 | 社区支持较弱 | 企业/微软生态 |
| **Oracle JDK** | 官方实现 | 商业授权复杂 | 不推荐普通玩家 |

在这里我依旧使用 **Melodify Blog** 的文章来进行说明各个 **Minecraft** 版本与 **JDK** 版本的对应关系

| **Minecraft版本** | **推荐Java版本** | **最低要求** | **说明** |
| --- | --- | --- | --- |
| **1.21及以上** | Java 25 |  | 见表格末尾 |
| **1.20.5及以上** | Java 21 | Java 21 | 必须使用Java 21，操作系统需64位 |
| **1.17 – 1.20.4** | Java 17 | Java 16 | 1.17是分水岭，核心迁移至Java 16+ |
| **1.12 – 1.16.5** | Java 8 / 11 | Java 8 | 对Java 8兼容性最好，模组兼容性稳定 |
| **1.11及以前** | Java 8 | Java 8 | 老版本基于Java 8构建，坚持使用最稳妥 |

::folding{title="1.21及以上 JDK说明"}
这一条是我添加的，我并不清楚1.21及以上需要多少版本的JDK，但是我使用 **1.21.1-fabric**客户端游玩一些模组的时候提示我最好使用 **JDK 24**，所以我推荐 **1.21及以上** 版本直接使用 **JDK 25** 。
