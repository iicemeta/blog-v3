## 前言

**Windows 10** 以前 Windows 并 **没有** 像手机一样的官方应用商店。直到 **Windows 10**，[Microsoft Store]{.text-story} 才被加入 Windows 中。

然而， **Microsoft Store** 并不是传统意义上的应用商店，而是专门为 **UWP应用** 设计的应用商店。

**UWP应用** 是微软官方为了推进 **Windows手机** 和 **Windows平板**，专门为触摸操作优化的应用。 **Microsoft Store** 正是为鼓励厂家设计 **UWP应用** 而诞生。

如今， **Microsoft Store** 已经全面开放，允许开发者上架 **Win32应用** （也就是大家熟知的一般的 Windows 软件）。

糟糕的是， **Microsoft Store** 上的应用很有限，而且大多数开发者不想对应用再进行打包从而发布到这里，这导致了这个商店并不好用。

因此，我们需要下载第三方应用商店。
