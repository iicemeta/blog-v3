**PCL2**（Plain Craft Launcher 2）是龙腾猫跃写的 Minecraft 启动器。免安装、绿色包，解压就能跑，下载和补 Java 都帮你安排好。

这篇教程从零开始，带你走完 **取压缩包 → 解压放置 → 首次启动 → 下载游戏 → 进入世界** 的全过程。

### 解压与放置

打开 **此电脑**，选择一个你喜欢的地方，这里我以 D 盘为例。**右击** 空白处，新建文件夹。

::alert{type="info" title="小技巧"}
按 :key{code="Win"} + :key{code="E"} 可以直接打开 **此电脑**。
::

::pic
---
src: https://postpic.iicemeta.com/how-to-install-Minecraft-PCL/image-10.png
caption: Windows 资源管理器 - 新建文件夹
---
::

这里我命名为 **PCL2**。

::pic
---
src: https://postpic.iicemeta.com/how-to-install-Minecraft-PCL/image-11.png
caption: Windows 资源管理器 - 命名为 PCL2
---
